Claude Code applies operating-system primitives to every Bash, PowerShell, and
Monitor command Claude runs, and to every process those commands spawn:
Seatbelt on macOS, bubblewrap on Linux and WSL2. Native Windows is unsupported,
so run Claude Code inside a WSL2 distribution there.

**Isolates:** writes, which default to the working directory, `--add-dir`
directories, and the per-user temp directory. Network access, where no domain
is pre-allowed.

**Still outside:** Read, Edit, and WebFetch run inside the Claude Code process
under permission rules instead. MCP servers and command hooks are separate
processes that run unconstrained on the host.

Reads default to the whole computer, `~/.ssh` and `~/.aws/credentials`
included, until you list them under `sandbox.credentials` or `denyRead`.
