Compaction replaces the conversation with a structured summary of what happened: what you asked for, what Claude decided, and the code that mattered.

**Survives:** your requests, key decisions, important code snippets, and all of startup (system prompt, `CLAUDE.md`, memory, MCP tools), which simply reloads.

**Lost:** most raw file contents, tool output, exact wording, and detailed instructions from early in the conversation. Claude Code re-reads up to five of the most recently touched files, so those come back. The skill descriptions do not reload either.

You can steer it. Run `/compact focus on the API changes`, or put a line in `CLAUDE.md` such as "when compacting, always preserve the list of modified files and any test commands" to say what must always be kept.
