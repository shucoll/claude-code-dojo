Projects are the fifth row on the official comparison, and this tree shows four.

A project is one ongoing conversation at claude.ai/code or in the desktop app.
Claude starts parallel cloud sessions called threads, gives each the project's
repositories, instructions, and memory, and shows you which ones need you. It is
in public beta on Pro, Max, and Ultra.

Reach for it when work spans many tasks over days or weeks and should keep
running while your machine is off. This curriculum is CLI-first and projects
have no terminal surface, so this tree only names it. See
[Projects](https://code.claude.com/docs/en/claude-projects) for the full
picture.
