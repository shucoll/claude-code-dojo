This is the phase a chat window cannot reach. Using tools, Claude edits files,
runs shell commands, runs your tests, or uses git.

Depending on the permission mode, it either asks you before edits and commands
or has a classifier screen them and block the risky ones. Every file edit is
snapshotted first, so you can rewind if you do not like the result.

Actions that touch systems outside your project, like deleting data or calling a
live service, are gated only by your permission mode and rules. A local snapshot
cannot undo those.
