This is the phase a chat window cannot reach. Using tools, Claude edits files,
runs shell commands, runs your tests, or uses git.

Depending on the permission mode, it either asks you before edits and commands
or has a classifier screen them and block the risky ones. Claude Code snapshots
each file before editing it, so you can rewind if you do not like the result.

A local snapshot cannot undo actions that touch systems outside your project,
like deleting data or calling a live service. You control those with your
permission mode and permission rules.
